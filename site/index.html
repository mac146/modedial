Modes for coding agents · MCP

Dial in your agent.

Say “debug mode” and your agent gets a tiny rulebook for the job. Six modes, one call, a printed label for every switch. Tested with Claude Code, Codex CLI and opencode.

$ claude mcp add modedial -- npx -y modedial

A mode is a nudge, not a lock: the tool hands over instructions and the agent decides. No telemetry, no network calls, no account.

The six modes

Each mode has a visible tell.

Each mode asks the agent to show its work in a recognizable way, so you can see which one is on, and screenshot it. Instructions stay under 150 tokens. Peel, drag, pick a sticker.

drag stickers anywhere

Not just advice

Some modes come with guards.

Instructions are a request. Where an agent supports hooks or permissions, modedial turns the important parts into guards that run as code, so they don't depend on the model choosing to follow along. They have limits, listed here.

Careful Reviewer

Its edit tools are blocked.

On Claude Code, file-edit tools are denied and leaving the mode needs your approval. Common file-changing shell commands are blocked too, but that filter is best effort, not a sandbox.

Debug Mode

One nudge to verify.

If it tries to finish after an edit with nothing run, it's sent back once to run the failing case or to say the fix is unconfirmed.

Deep Focus

Edits stay inside the lines.

The agent declares the files it expects to change. Editing anything else with its file tools needs your approval, and so does widening the list. It's asked to open with the goal and close with what it set aside.

Chill Refactor

Dependencies stay put.

File-tool edits to package.json, lockfiles and other manifests need your approval; shell installs aren't caught. It's reminded once to run something and to say what changed.

EnforcedClaude Code (the hooks above) and opencode (the reviewer's edit and shell tools are off). Roo Code modes declare tool limits we haven't run.
Rules onlyCursor, Windsurf, Cline, Codex and Gemini CLI get the guards written into the mode as plain rules, because they can't enforce them. Codex also has its own read-only sandbox.
How we knowThe guards are unit-tested, and checked against real Claude Code and opencode sessions. We did not benchmark whether modes improve results, and make no such claim.

How it works

Three steps, no account.

  1. Add the server

    One command registers it with your agent. Paste the short snippet into CLAUDE.md or AGENTS.md so the agent uses it reliably.

  2. Ask for a mode

    “Debug mode.” The agent calls set_mode and follows the instructions it gets back.

  3. Keep the card

    Export the latest mode card, or the recap, and post it if you like.

Install

Pick your agent.


    

    
Every agent: npx modedial install lists them, and npx modedial install <agent> writes that agent’s native files. Claude Code, opencode and Codex are checked against real sessions. Cursor, Windsurf, Cline and Roo Code follow their docs. Copilot, Gemini CLI, Kilo Code and Aider are unverified.

    
To switch on the Claude Code guards: npm install -g modedial, then modedial install claude-code. They run on every edit, so they need the global install to start fast.

  


  

    
Plainly

    
Fine print, because we like you.

    

      
What you get
  • Six bundled modes, each under 150 tokens, some with guards where the agent supports them.
  • A card on every switch, and a recap from your own log.
  • Open source, MIT licensed.

      
What we don’t claim
  • That modes improve results. We haven’t measured that, and one study of similar instruction files found more cost, not better success.
  • That agents feel anything. These are instructions, not moods.
  • That an MCP tool can force behavior. It can’t.
