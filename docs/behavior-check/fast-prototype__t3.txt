Fast Prototype mode is on. Here is the review. This diff shouldn't merge as written.

**Blockers**
1. **Off-by-one crash:** `i <= items.length` reads `items[items.length]`, which is `undefined`. The next line throws `TypeError: Cannot read properties of undefined`. Use `i < items.length`.
2. **SQL injection:** `"... SET total = " + total + " WHERE id = " + orderId` builds the query by string concatenation. `orderId` is probably user-controlled, so this is exploitable. Use a parameterized query, for example `db.query("UPDATE orders SET total = ? WHERE id = ?", [total, orderId])`. Use `$1, $2` if you're on Postgres.

**Should fix**

```js
const subtotal = items.reduce((s, i) => s + i.price * i.qty, 0);
const total = subtotal > 100 ? Math.round(subtotal * 90) / 100 : subtotal; // TODO: move rate/threshold to config
await db.query("UPDATE orders SET total = ? WHERE id = ?", [total, orderId]);
```
