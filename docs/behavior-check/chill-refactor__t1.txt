**Fix:** the bug is the `- 1` in the slice end. `slice(start, end)` already excludes `end`, so `start + size - 1` returns only `size - 1` items.

```js
function paginate(items, page, size) {
  const start = page * size;
  return items.slice(start, start + size);
}
```

- This fix is a behavior change, which goes beyond this mode's usual tidy-only scope. I made it because it's the task you asked for.
- `page` is 0-indexed. If callers pass 1-indexed pages, they'll skip the first page. I haven't checked the callers.
- I have no tests here and can't run anything. Add a quick test, for example `paginate([1,2,3,4,5], 0, 2)` should give `[1,2]`.
