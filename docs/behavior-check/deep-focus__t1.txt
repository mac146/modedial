Goal: Fix `paginate` so it stops dropping the last item of each page.

**Cause:** `slice(start, end)` already excludes `end`. `start + size` is the correct end index, so the extra `- 1` cuts off one item per page.

**Fix:**
```js
function paginate(items, page, size) {
  const start = page * size;
  return items.slice(start, start + size);
}
```

Pages are 0-indexed here. If callers pass 1-indexed pages, `start` should be `(page - 1) * size`. That would be a separate bug, and your report doesn't suggest it.

Set aside:
- `fmt` isn't part of this bug, so I didn't touch it. It uses `var` and doesn't zero-pad month or day. It also gives `NaN/NaN/NaN` for invalid dates.
